# Brand readiness

Public name remains **TypeFlow** pending owner approval. No domains, trademarks, subscriptions or services were purchased.

`src/lib/brand.ts` centralizes the product name, tagline and logo path. The shared web brand consumes it. Obsidian Blue colors are centralized in `src/styles-tokens.css` and imported by both surfaces. Internal storage keys, package name, extension identity, manifest OAuth configuration and Google scope remain stable.

A future approved rename should update the shared copy, remaining public page copy, metadata, manifest display strings and store assets together. Do not regenerate the extension public key, change OAuth clients, rename storage namespaces or change the package identifier for a cosmetic rename. Search public copy for TypeFlow before the rename; not every explanatory sentence is dynamically interpolated today.

No candidate name has been selected or cleared. Owner approval and independent domain/trademark availability checks remain necessary before finalizing a new public name. No superiority or human-authorship claims should accompany a rebrand.
